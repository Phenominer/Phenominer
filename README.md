## 🛡️ IBVAP — Intelligent Border Video Analytics Platform

> A software-defined, edge-deployed AI surveillance platform that extracts actionable intelligence from existing CCTV infrastructure — eliminating dependence on expensive dedicated hardware.

<details>
<summary><b>⚡ Core AI Capabilities</b></summary>
<br/>

| Capability | Description |
|---|---|
| 🧠 **Human & Vehicle Detection** | Real-time multi-class tracking across camera feeds |
| 👤 **Face Detection & Recognition** | Authorized person database, watchlist & blacklist matching |
| 🚗 **ANPR** | Automatic number plate reading with whitelist / blacklist / watchlist management |
| 🚧 **Virtual Fence** | Configurable boundary-crossing alerts with instant notification |
| 🌙 **Night-time Detection** | IR / low-light processing mode |
| 📊 **Suspicious Activity** | Behavioral pattern flags — loitering, climbing, perimeter breach |
| ⚡ **Real-time Alerts** | Event logging, alert generation, and officer dispatch |

</details>

<details>
<summary><b>🏗️ Architecture Highlights</b></summary>
<br/>

- **Edge Node** — each region runs its own AI inference node; cameras → isolated VLAN → Edge Node
- **Central Platform** — thin coordinator; receives only metadata, alerts & health pings — no raw video streaming
- **Offline Resilience** — detection, recording and event storage continue uninterrupted during connectivity loss
- **On-Demand Footage** — full clips only transferred when explicitly authorized by command center
- **Prototype → Production** — identical software stack scales from laptop + smartphone cameras to full IP CCTV deployment

</details>
